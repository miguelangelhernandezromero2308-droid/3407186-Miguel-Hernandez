## 📖 Descripción del Proyecto

En esta tercera semana se desarrolló una **calculadora aplicada al dominio del Sistema de Citas Médicas Online**.  

El objetivo es aplicar los diferentes **operadores de JavaScript** para realizar cálculos relacionados con el funcionamiento de un sistema médico digital, como ingresos por consultas, citas disponibles, asignación de pacientes y validaciones del sistema.

Este ejercicio simula operaciones que podría realizar un sistema real de gestión de citas médicas.

---

## 🎯 Objetivo

Construir una **calculadora multi-operación** utilizando operadores de JavaScript para resolver cálculos relacionados con un **sistema de citas médicas online**.

---

## 🧠 Conceptos Aplicados

Durante el desarrollo de esta actividad se aplicaron los siguientes conceptos:

- Operadores aritméticos (`+`, `-`, `*`, `/`, `%`)
- Operadores de asignación compuesta (`+=`, `-=`, `*=`, `/=`)
- Comparación estricta (`===`, `!==`, `>=`, `<=`, `>`, `<`)
- Operadores lógicos (`&&`, `||`, `!`)
- Separadores numéricos (`1_000_000`)
- Uso de `console.log()` para mostrar resultados
- Variables y constantes en JavaScript

---

## 🏥 Dominio del Proyecto

El dominio asignado es:

**Sistema de Citas Médicas Online**

Este sistema simula operaciones como:

- Cálculo de ingresos por consultas médicas
- Número de citas disponibles
- Promedio de ingresos por médico
- Validaciones del sistema de citas
- Aplicación de descuentos o promociones

## ▶️ Ejecución del Proyecto

Para ejecutar el proyecto se debe utilizar **Node.js**.

1. Abrir la terminal.
2. Ubicarse en la carpeta del proyecto.
3. Ejecutar el siguiente comando:

```
node starter/script.js
```
