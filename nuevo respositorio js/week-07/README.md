## 📖 Descripción del Proyecto

En esta séptima semana se desarrolló una **librería de funciones reutilizables** aplicada al dominio **Sistema de Citas Médicas Online**.

El objetivo fue crear funciones independientes que permitan procesar información de citas médicas, separando la lógica del sistema de la presentación de resultados.

Este enfoque permite construir un código más organizado, reutilizable y escalable, como en sistemas reales.

---

## 🎯 Objetivo

Implementar funciones reutilizables que permitan:

- Formatear información de citas
- Realizar cálculos sobre los datos
- Validar estados de las citas
- Generar reportes dinámicos

---

## 🧠 Conceptos Aplicados

Durante esta actividad se aplicaron los siguientes conceptos:

- Funciones en JavaScript
- Arrow functions
- Parámetros y valores de retorno (`return`)
- Funciones puras
- Parámetros por defecto
- Separación de lógica y salida
- Uso de funciones como callbacks
- Template literals

---

## 🏥 Dominio del Proyecto

El dominio asignado es:

**Sistema de Citas Médicas Online**

El sistema permite:

- Gestionar múltiples citas médicas
- Evaluar el estado de cada cita
- Calcular totales de atención
- Generar reportes dinámicos
- Reutilizar lógica mediante funciones
